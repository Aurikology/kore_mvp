# Overview

KORE is a non-invasive neurotechnology platform that pairs a wearable brain patch with an AI-native application. The goal is to help students manage cognitive overload, reduce anxiety, and replace unhealthy chemical dependencies with a safe, intentional reset loop.

## Target Users
- College students under sustained academic stress.
- Individuals with high cognitive load and focus volatility.

## Value Proposition
- Always-on cognitive load monitoring.
- Predictive alerts before burnout or focus crashes.
- Gentle, closed-loop neuromodulation to restore balance.

## UX Principles
- Minimal, clean interface with low visual burden.
- High readability and predictable interaction patterns.
- Fast insight delivery with low cognitive overhead.
