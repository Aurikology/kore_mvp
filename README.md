# KORE

The digital dashboard for your mind. KORE is a high-performance, non-invasive neurotechnology platform designed to monitor cognitive load, reduce burnout, and provide a healthy alternative to chemical dependencies like vapes and nicotine pouches.

## Overview
KORE combines an always-on wearable brain patch with an AI-native cross-platform application. The system continuously monitors cognitive strain, predicts overload, and applies gentle neuromodulation to help users recover focus and reduce anxiety.

## How It Works
1. Sensing (EEG micro-volt analysis)
   - Tracks raw microvolt potentials from the dorsolateral prefrontal cortex (dlPFC).
   - Monitors alpha suppression (focus loss) and frontal theta spikes (working memory overload).
2. AI-native prediction
   - Converts incoming telemetry into a Cognitive Bandwidth Meter score (0-100).
   - Identifies impending focus crashes or craving signals.
3. Targeted neuromodulation (the reset)
   - Initiates an ultra-low microcurrent session (< 2mA).
   - Entrainment at baseline alpha frequency (10 Hz) to restore calm focus.

## Product Vision
